Stage 2: Detect

First pass only Finds common identifiers plus the names you list — still read the result. Why?

This does a thorough first pass.

It reliably finds common things like emails, phone numbers and ID numbers, plus the names you list below. It can still miss things only a person would notice. Always read the result yourself before you rely on it.

Detection settings
Jurisdiction national-ID packs

Off by default. Turn on the jurisdictions you work in to also flag their national IDs (e.g. Singapore NRIC/UEN, US SSN).

Party / names to redact

Add names or terms you already know must be redacted.

The known names a detector can’t guess — people, counterparties, project codenames, reference numbers (one per line). Each is matched literally and case-insensitively wherever it appears, so a bare “Massimo Greco” with no title is caught. This is the reliable way to redact a known name.

Import a .csv or .txt list of names — they’re added to the box above.

Keep (never redact)

Names or values to leave visible — e.g. your client’s own name or IC. Anything here is still found and shown in Review, but marked “kept” and left in the document (you can overturn any of them with one click). Keeping is your choice — the tool still shows you what it found. One per line.

Recognizers

All on by default (best recall). Untick one to STOP flagging it for this document — this reduces what gets found, so use it only for a built-in that is pure noise on your corpus. All / Default here also cover Context, LEI and the Compliance profile below.

A compliance profile that requires a recognizer (e.g. PCI needs the card recognizer) keeps it on even if unticked here.

Context-sensitive detection

More recall, but more false positives — review each careful-review item.

Legal Entity Identifiers (LEI)

Off by default — a public LEI is borderline personal data, so flagging it is your call. The checksum keeps false positives low.

Aggressive SG NRIC (advisory)

Review-only, never redacted unless you tick them. Off by default — a wide net for NRIC-shaped text the precise NRIC recognizer skips. A real NRIC is still caught and redacted by default; these are the EXTRA possibles.

Organisation names

Off by default. Every hit is a careful-review item, never auto-redacted. A person’s name always wins over an overlapping organisation match, so a director is redacted as a name, not a company.

Full addresses

Off by default. Broader reach means more to review. In the labelled-placeholder export a person who sits inside an address (e.g. “Dr … House”) can be labelled [address] — still redacted, never a leak, but read the placeholders before you send.

Compliance profile

Deterministic matching cannot cover cardholder names or free-text account references — those stay your review responsibility.
